# Nhập môn CSS Grid cho người mới bắt đầu

## Content
Bài học trình bày cách dùng CSS Grid để dựng layout 2 chiều, có ví dụ minh hoạ
kèm bài tập thực hành ở cuối bài, đủ chi tiết cho người mới.

## Learning Outcome
- Phân biệt được khi nào nên dùng Grid thay vì Flexbox.
- Dựng được layout responsive dùng grid-template-columns.

## Prerequisite
- Đã học CSS Box Model và Selectors cơ bản.

## Terminology
- Grid container: phần tử cha được đặt display: grid.
