# Evidence - Day 28

Lưu bằng chứng thực tế của buổi UAT tại đây, ví dụ:

- Ảnh màn hình từng kịch bản (`UAT-01`, `UAT-02`, ...).
- Log lỗi hoặc response liên quan.
- Ảnh/biên bản xác nhận của giảng viên nếu được phép lưu.
- Phiên bản hoặc commit đã kiểm thử.

Không đưa mật khẩu, token, dữ liệu cá nhân hoặc dữ liệu nhạy cảm thật vào thư mục này.
