# Reports

Thư mục này chỉ giữ evidence nhỏ, đã làm sạch và phù hợp để commit. Mỗi file phải ghi ngày, lab, nguồn kiểm tra và kết luận giới hạn.

Playwright HTML report, trace và screenshot nằm trong `automation/reports` hoặc `automation/test-results`; các thư mục đó bị ignore vì có thể lớn hoặc chứa dữ liệu phiên chạy. Chỉ commit bản tóm tắt đã loại credential.
