# CS-CRS-002: Lộ trình đào tạo chuyên sâu Data & AI Resource Engineer

## SEC-CRS-002-01: Mục tiêu đào tạo và chuẩn đầu ra Data & AI Resource Engineer

Khóa học đào tạo trong 05 tháng (200 giờ giảng dạy trực tiếp), tập trung trang bị kỹ năng chuyên sâu về Kiến trúc dữ liệu quan hệ, Thiết kế bộ dữ liệu tổng hợp (Synthetic Data Generation), Xây dựng hệ thống tìm kiếm ngữ nghĩa và RAG (Retrieval-Augmented Generation), cùng quy trình đánh giá và kiểm thử chất lượng mô hình ngôn ngữ lớn (LLM Evaluation & Benchmarking).

## SEC-CRS-002-02: Cấu trúc 04 Module chuyên môn trọng tâm

Module 1: Relational Data Modeling & Advanced SQL (Thiết kế Star Schema, Window Functions, Stored Procedures, Tối ưu Query Plan). Module 2: Data Quality Harness & Synthetic Generation (Sử dụng Faker, Pydantic, gài cắm lỗi chủ ý có kiểm soát, kiểm định toàn vẹn chéo). Module 3: Vector Embeddings & RAG Architecture (Chunking strategies, ChromaDB/Pinecone, Hybrid Search, Reranking, Metadata filtering). Module 4: LLM Evaluation, Guardrails & Anti-Leakage (Xây dựng tập test benchmark, đo lường Faithfulness, Answer Relevance, Context Recall và triển khai pipeline CI/CD kiểm thử tự động).

## SEC-CRS-002-03: Đồ án Capstone cuối khóa chuyên ngành AI

Đồ án tốt nghiệp yêu cầu xây dựng một Hệ thống Trợ lý Tri thức Thông minh (Enterprise Knowledge Assistant) hoàn chỉnh: Tự động thu thập tài liệu nội bộ, trích xuất metadata, chunking và sinh vector embeddings, hỗ trợ truy vấn hỏi đáp RAG có trích dẫn nguồn (Citations), bảo vệ chống tiêm nhiễm prompt (Prompt Injection Defense) và đạt điểm kiểm thử F1-score retrieval tối thiểu 85% trên tập dữ liệu benchmark 100 câu hỏi.

## SEC-CRS-002-04: Yêu cầu đầu vào và kiến thức tiên quyết

Học viên cần nắm vững kiến thức lập trình cơ bản bằng ngôn ngữ Python (kiểu dữ liệu, vòng lặp, hàm, làm việc với file JSON/CSV) và toán xác suất thống kê cơ bản trước khi tham gia khóa học.
