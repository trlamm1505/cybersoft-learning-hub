# CS-CRS-001: Lộ trình đào tạo chuyên sâu Fullstack Web Developer NodeJS & React

## SEC-CRS-001-01: Mục tiêu đào tạo và chuẩn đầu ra Fullstack Web

Chương trình đào tạo trong thời lượng 06 tháng (tương đương 240 giờ học trực tiếp kèm 300 giờ thực hành đồ án), trang bị cho học viên năng lực xây dựng hoàn chỉnh ứng dụng web Single Page Application (SPA) hiện đại từ giao diện người dùng (Frontend) đến hệ thống dịch vụ dữ liệu và API phía sau (Backend), sẵn sàng ứng tuyển vị trí Junior Fullstack Web Developer hoặc Frontend/Backend Specialist tại doanh nghiệp.

## SEC-CRS-001-02: Cấu trúc 03 giai đoạn học tập chi tiết

Giai đoạn 1 (Tháng 1-2): Nền tảng lập trình web hiện đại với HTML5/CSS3, Responsive Web Design, Bootstrap 5, Tailwind CSS và JavaScript ES6+ chuyên sâu (Async/Await, Closures, DOM Manipulation). Giai đoạn 2 (Tháng 3-4): Frontend Framework chuyên sâu với ReactJS 18, React Hooks, React Router DOM v6, Quản lý State toàn cục bằng Redux Toolkit và tối ưu hiệu năng UI. Giai đoạn 3 (Tháng 5-6): Backend kiến trúc RESTful API với NodeJS, ExpressJS, ORM Prisma/Sequelize kết nối cơ sở dữ liệu PostgreSQL, xác thực bảo mật JWT, triển khai Docker và Cloud Render/AWS.

## SEC-CRS-001-03: Đồ án Capstone cuối khóa và bảo vệ hội đồng

Đồ án Capstone cuối khóa yêu cầu phát triển hoàn thiện một nền tảng Thương mại điện tử (E-commerce) hoặc Hệ thống Mạng xã hội thu nhỏ. Đồ án phải tích hợp đầy đủ các tính năng: Xác thực phân quyền Role-based, Giỏ hàng thời gian thực, Tích hợp cổng thanh toán trực tuyến (VNPay/ZaloPay Sandbox), Upload ảnh Cloudinary, và Deploy CI/CD tự động lên Vercel và Render.

## SEC-CRS-001-04: Yêu cầu đầu vào và công cụ hỗ trợ

Khóa học không yêu cầu kiến thức lập trình trước đó, chỉ cần có tư duy logic cơ bản và kỹ năng sử dụng máy tính văn phòng. Học viên được cấp miễn phí tài khoản GitHub Copilot Student, máy chủ sandbox thực hành và kho video bài giảng bổ trợ trọn đời.
