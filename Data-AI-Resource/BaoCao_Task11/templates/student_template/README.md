# 🎓 CyberSoft Student Project Starter Template

Chào mừng học viên đến với dự án thực hành thuộc **CyberSoft Project Bank**.

## 📁 Cấu Trúc Dự Án Học Viên
```text
├── PROJECT_BRIEF.md          # Đề bài, bối cảnh nghiệp vụ, danh sách nhiệm vụ chi tiết
├── data/                     # Thư mục chứa tập dữ liệu thực hành (CSV/JSON/Parquet)
├── starter_kit/              # Mã nguồn khung khởi đầu (Python script, SQL template)
├── rubric.json               # Barem thang điểm 100 với tiêu chí định lượng minh bạch
├── HINTS.md                  # Gợi ý phân tầng 3 cấp độ (khi gặp khó khăn)
└── submission_checklist.md   # Bảng kiểm tra trước khi nộp bài
```

## 🚀 Hướng Dẫn Thực Hiện
1. Đọc kỹ file [PROJECT_BRIEF.md](./PROJECT_BRIEF.md) để nắm rõ bối cảnh và yêu cầu.
2. Kiểm tra [rubric.json](./rubric.json) để biết tiêu chí chấm điểm và mức điểm của từng phần.
3. Sử dụng code trong thư mục `starter_kit/` để bắt đầu làm bài.
4. Nếu gặp vướng mắc, hãy tham khảo [HINTS.md](./HINTS.md) theo từng Tier (không nên đọc ngay Tier 3).
5. Trước khi nộp, đối chiếu với [submission_checklist.md](./submission_checklist.md).
