# CS-CRS-003: Lộ trình đào tạo chuyên sâu DevOps & Cloud Computing AWS

## SEC-CRS-003-01: Mục tiêu đào tạo và chuẩn đầu ra DevOps AWS

Chương trình đào tạo kéo dài 4.5 tháng (180 giờ học), rèn luyện cho học viên tư duy tự động hóa hạ tầng (Infrastructure as Code), quy trình tích hợp và phân phối liên tục (CI/CD), điều phối container quy mô lớn với Kubernetes (K8s), và quản trị kiến trúc điện toán đám mây theo chuẩn AWS Well-Architected Framework, hướng tới chứng chỉ quốc tế AWS Certified Solutions Architect Associate.

## SEC-CRS-003-02: Nội dung chi tiết các học phần cốt lõi

Học phần 1: Quản trị hệ thống Linux căn bản & Bash Shell Scripting tự động hóa. Học phần 2: Containerization với Docker đa tầng và điều phối cụm Kubernetes (EKS, Deployment, Service, Ingress, Helm Charts). Học phần 3: Xây dựng Pipeline CI/CD tự động bằng GitHub Actions và GitLab CI. Học phần 4: Khởi tạo hạ tầng tự động hóa bằng Terraform (IaC) và quản trị cấu hình Ansible. Học phần 5: Giám sát toàn diện hệ thống với cụm Prometheus, Grafana và EFK Stack (Elasticsearch, Fluentd, Kibana).

## SEC-CRS-003-03: Dự án thực chiến Capstone Cloud Infrastructure

Học viên tự tay thiết kế và triển khai một hạ tầng đám mây phân tán High Availability (HA) trên AWS phục vụ hệ thống microservices: Tự động scale tải với Auto Scaling Groups, phân phối lưu lượng qua Application Load Balancer, lưu trữ an toàn trên Amazon RDS Multi-AZ, cấu hình mã hóa khóa KMS, và tự động deploy ứng dụng qua GitHub Actions Runner.

## SEC-CRS-003-04: Tài trợ chi phí Cloud thực hành

Mỗi học viên được CyberSoft tài trợ mã kích hoạt tài khoản AWS Educate với hạn mức 100 USD để tự do khởi tạo máy chủ EC2, cụm VPC và dịch vụ cơ sở dữ liệu trong suốt thời gian học mà không tốn phí cá nhân.
