# QUY CHUẨN THƯ MỤC NOTEBOOKS

Thư mục này chứa các sổ tay thí nghiệm Jupyter Notebook phục vụ cho việc:
* Khảo sát dữ liệu thăm dò (Exploratory Data Analysis - EDA).
* Thử nghiệm tham số mô hình embedding và chunking.
* Đánh giá trực quan các ca kiểm thử RAG.

### Quy tắc đặt tên notebook:
* Định dạng: `XX_<tên_ngắn_gọn>.ipynb` (Ví dụ: `01_eda_course_data.ipynb`, `02_embedding_benchmark.ipynb`).
* Trước khi commit notebook, hãy xóa sạch output (`Clear All Outputs`) để tránh làm phình repository và rò rỉ dữ liệu.
